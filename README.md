# YADORA

*Yet another dang ole ROM app.* A Mac app for organizing a game ROM collection, built on [Igir](https://github.com/emmercm/igir).

## Download

**[Download the latest YADORA](https://github.com/caheitmann/yadora-releases/releases/latest)**: open the `.dmg` and drag YADORA onto Applications.

- Works on Apple silicon and Intel Macs with macOS 14 or later.
- Signed and notarized by Apple, so it opens with no warnings.
- Updates itself: it checks once a day and offers the new version (or use YADORA › Check for Updates…).
- Never changes your original files: it only reads them and copies what you pick into a separate folder.
